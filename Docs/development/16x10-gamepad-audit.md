# 16:10 与原生手柄适配审计记录

## 已确认的基础事实

- `dev/16x10-gamepad` 已包含自动拾取交互 ROI 的中心锚定修复；本次保留该行，没有覆盖。
- 识别资源通过 `RecognitionObjectJsonLoader` 解析 ROI，截图通常先由 `GameCaptureRegion.DeriveTo1080P()` 统一缩放。
- 输入统一经过 `InputHub`、`IInputBackend`、`IInputChannel`；原有 Win32 前台/后台通道保持不变。
- ViGEm/Xbox 360 后端只能输出虚拟手柄状态，不能读取或发送 XInput 输出；运行时必须安装 ViGEmBus 驱动。

## 本次落地范围

- 增加 1920x1080 参考画布到当前截图的等比映射，支持左上、右上、左下、右下、中心锚点和边界裁剪。
- Recognition JSON 增加 `anchorTopLeft`、`anchorTopRight`、`anchorBottomLeft`、`anchorBottomRight`、`anchorCenter`。
- 更新已确认属于中心、右上或右下布局的自动吃药、秘境、开宝箱、音游和快捷购买 ROI；自动拾取现有提交行保持不变。
- 增加 ViGEm Xbox 360 虚拟手柄通道、动作映射、摇杆/扳机、保持与释放、异常停止清理，以及可注入的测试设备。
- 在现有“设置 → 按键设置”列表中增加“手柄绑定”下拉列。键鼠和手柄动作在同一行配置，支持按钮、扳机、摇杆方向和“未映射”；不会把键盘物理键码当作手柄按钮，也不会覆盖原神内的自定义键位。
- 手柄映射的默认值只用于首次初始化。用户按原神控制器界面实际显示的按钮，在对应动作同一行重新选择即可；原神没有暴露为独立控制器动作的项目可以保持“未映射”。
- 增加键鼠与手柄 Recognition profile 扩展点。profile 现在按截图分辨率选择；没有对应真实手柄素材时自动回退到原键鼠素材，不生成伪模板。
- 根据用户提供的 2560x1600 控制器 HUD 截图，增加 1920x1200 归一化的 RT 拾取提示模板。自动拾取识别到 RT 后发送 `PickUpOrInteract`，包括新增的多物品拾取画面；剧情选项、前往冒险家协会和“走到交互键”也共用这条手柄输入调用链。
- 根据用户提供的地图和剧情截图，增加 1920x1200 的手柄识别 profile：地图用左下角齿轮确认地图状态、右下角 B 识别离开提示；剧情用右下角“确认”文字识别手柄对话界面。识别 profile 与输入后端分离，仍按实际截图分辨率选择；因此自定义确认按钮图标不会影响剧情识别。
- 自动拾取、剧情确认和剧情菜单关闭已优先改为动作/焦点导航调用；手柄剧情转场的短暂 Unknown UI 仍保持触发器调度，避免自动剧情中断。钓鱼交互、取消和音游音符也已接入统一手柄动作映射。地图、战斗中的鼠标镜头和仍直接依赖坐标点击的任务不因此自动获得控制器 UI 支持。
- 启动时的比例检查统一接受 16:9 与 16:10；2560x1600 不再触发“不是 16:9”的误报。未提供对应素材或仍有旧任务专用比例假设的功能，仍需单独验证。
- 首页“启动”卡片增加“运行输入模式”选择。键鼠模式与手柄模式分别创建对应输入后端和识别 profile；运行中切换会先停止当前绑定再重新绑定，避免两套输入和识别逻辑混用。

## 本机可重复测试

- 已确认 ViGEmBus 设备正常枚举为 `Virtual Xbox 360 Controller`。
- 已通过实际 ViGEm 设备发送 A 按键，并用 XInput 读取到按下与释放状态。
- 定向单元测试覆盖默认 Xbox 映射、自定义动作映射、按键按下/释放、直接 VK 动作反查、状态清理和 16:10 坐标转换。
- 自定义键位验证路径：进入“设置 → 按键设置”，在对应动作的“手柄绑定”下拉选择原神当前提示的实际按钮；启动原神控制器模式后先用拾取、剧情确认或基础移动验证。单元测试只验证映射和虚拟设备状态，不等于原神实机兼容。
- 上述测试不等于原神实机兼容；原神控制器模式、游戏内 UI 焦点和自动任务仍需在游戏中验证。

## 尚需实机材料

- 手柄模式下的对话选项列表、地图点位选中后的传送详情面板、地图拖动/缩放过程、角色/队伍及战斗 UI 截图，仍需要 1920x1200 和 2560x1600 的对应状态。当前已收到并接入地图基础界面、剧情确认界面和多物品 RT 拾取界面截图，但仍需要运行时触发验证。
- 真实 Windows 环境中安装 ViGEmBus 后的虚拟手柄枚举、原神控制器模式识别，以及真实手柄与虚拟手柄同时连接时的设备选择结果。
- 自动战斗、寻路、钓鱼、七圣召唤等任务的控制器模式截图和操作录像；当前没有据此新增模板或声称已验证。
